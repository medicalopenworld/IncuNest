### Task 3: Reubicar el knob `INCUNEST_PPG_TIMING` y poner el guard de clon limpio

**Files:**
- Modify: `Firmware/motherBoard/CMakeLists.txt` (16 líneas hoy; se le añaden dos bloques)

**Interfaces:**
- Consumes: el componente de Task 2
- Produces: la variable de entorno `INCUNEST_PPG_TIMING` define `INCUNEST_TIMING_STATS=1` para **todos** los componentes del build

**Por qué esto es lo delicado de todo el cambio:** `#if INCUNEST_TIMING_STATS` **añade miembros a la clase `INCUNEST_AFE4490`**, así que cambia su `sizeof`. Esa cabecera la incluyen `SPO2.h`, `DriveUpload.h` y `PpgSnapshot.h`. Si el define llega solo a unas unidades de traducción y no a otras, cada lado ve una clase de tamaño distinto: **corrupción de memoria silenciosa, no error de enlazado**. El CMakeLists viejo lo resolvía con `target_compile_definitions(... PUBLIC ...)`. Como ese fichero ya no es nuestro, se usa `idf_build_set_property`, que alcanza a todo el build — estrictamente más seguro.

Tras este cambio el AFE abre su propio device por `spi_bus_add_device` desde su HAL, y `plat_spi` en `motherBoard` existe **solo para levantar el bus** con `spi_bus_initialize(SPI2_HOST)`. ```cpp

// Bus SPI maestro sobre driver/spi_master (ESP-IDF puro).
//
// Se le da la FORMA de la API SPI de Arduino —begin / beginTransaction /
// transfer / endTransaction, con SPISettings— y se publica un objeto global
// llamado SPI, por el mismo motivo que millis() y String: minimizar el delta
// del codigo portado desde Arduino.
//
// QUE QUEDA DE ESTO EN CADA PLACA, TRAS PASAR EL AFE4490 A SUBMODULO v0.92:
//
//   motherBoard: SOLO el spi_bus_initialize() de begin(). La libreria del
//     AFE4490 dejo de pasar por aqui — desde v0.91 tiene su propio HAL de
//     ESP-IDF y abre su device con spi_bus_add_device(SPI2_HOST). Pero SIGUE
//     NECESITANDO que alguien inicialice el bus antes, y ese alguien es este

// SPI.transfer(uint8_t) escribiendo directamente los registros del periferico
// (spiTransferByteNL), sin interrupciones. Aqui se usa
// spi_device_polling_transmit(), que tambien va por sondeo, sin interrupciones
// ni DMA: el coste por byte queda en el mismo orden.
//
// La duda que este fichero dejaba abierta sobre la cadencia de las muestras de
// PPG ya no se responde aqui: la mide la propia libreria. Compila con
