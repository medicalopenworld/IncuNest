# Elemento calefactor

**Usada por las alarmas:** 1, 2, 12, 17

La resistencia, entera y de perfil. Importa su forma real: hoy el modelo la dibuja como un muelle o como un simbolo de resistencia, y ninguna de las dos se parece. Si esta detras de una rejilla, una foto con la rejilla puesta y otra sin ella.

Deja aqui los ficheros .jpg o .png sin mas. El script los reescala a 1024 px antes de enviarlos, asi que no hace falta prepararlos.

Si esta carpeta se queda vacia no pasa nada: el script avisa y genera igual, con la forma inventada que tiene hoy.
