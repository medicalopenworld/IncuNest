# Panel del display

**Usada por las alarmas:** 14, display

El display montado, su soporte, y el cable que baja a la placa. Sale en dos escenas y en ambas hay que dibujar ese cable roto.

Deja aqui los ficheros .jpg o .png sin mas. El script los reescala a 1024 px antes de enviarlos, asi que no hace falta prepararlos.

Si esta carpeta se queda vacia no pasa nada: el script avisa y genera igual, con la forma inventada que tiene hoy.
