# Notas de trabajo (Alex)

Material de trabajo de las sesiones de desarrollo de Alex: briefs entre
sesiones, análisis preliminares, notas de investigación y guías de uso de las
herramientas. **No es documentación del firmware ni está revisada**; Pablo
puede ignorar esta carpeta.

Lo que de aquí madura y afecta al proyecto pasa a su sitio oficial:
requisitos a `Firmware/openspec/` (change → spec), decisiones a
`Firmware/docs/adr/`, y el relato de un cambio terminado a `Firmware/docs/retro/`.

Convención de nombres: `AAAA-MM-DD-tema.md`, fecha de creación delante, como
en `docs/retro/`.
